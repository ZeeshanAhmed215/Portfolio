# Zeeshan Ahmed Noonari — Portfolio

A responsive static portfolio for Zeeshan Ahmed Noonari, a BS Artificial Intelligence student and AI/ML developer at DUET Karachi.

## Run locally

Open `index.html` directly, or serve the folder with:

```powershell
cd "Portfolio"
python -m http.server 4173
```

Then visit `http://localhost:4173`.

## Deploy

This project has no build step and can be deployed directly to GitHub Pages or Vercel.

The GitHub Projects section loads public repositories dynamically from:

`https://api.github.com/users/ZeeshanAhmed215/repos?sort=updated`
